# GENESIS · 차량 갤러리 웹 포트폴리오

> 차량의 첫인상에서 상세 정보 탐색까지, 이미지와 인터랙션으로 연결하는 웹 퍼블리싱 프로젝트

**Genesis Concept Car Gallery**  
Publisher · **김소연 (kim so yeon)**

제네시스 차량 이미지를 중심으로 풀스크린 캐러셀과 모델별 상세 페이지를 구현한 학습용 포트폴리오입니다. HTML, CSS, JavaScript를 활용해 자동재생, 드래그·스와이프, 스크롤 애니메이션을 구현했습니다.

## 02. 기획 의도

- **이미지 중심의 첫 화면** — 차량 이미지를 화면 전체에 배치해 모델의 디자인과 분위기를 전달합니다.
- **자연스러운 탐색 흐름** — 캐러셀에서 관심 있는 차량을 선택하면 해당 모델의 상세 페이지로 이어집니다.
- **기기별 조작 방식** — PC에서는 마우스 드래그, 모바일에서는 터치 스와이프로 차량을 탐색합니다.
- **일관된 시각적 표현** — 어두운 배경과 큰 타이포그래피, 여백을 활용해 차량 이미지에 집중할 수 있도록 구성했습니다.

## 03. 메인 이미지

![메인 대표 이미지 — G90 LONG WHEEL BASE](docs/images/01-g90-long-wheel-base.avif)

*프로젝트에 사용된 차량 이미지입니다. 실제 메인 페이지 화면 캡처는 아닙니다.*

메인 페이지는 8개 차량 이미지를 보여주는 풀스크린 갤러리입니다. 차량명, 소개 문구, 현재 슬라이드 번호를 표시하고 좌우 버튼과 하단 인디케이터로 탐색을 돕습니다.

## 04. 서브 이미지

![서브 대표 이미지 — GV80 COUPE](docs/images/03-gv80-coupe.avif)

*프로젝트에 사용된 차량 이미지입니다. 실제 상세 페이지 화면 캡처는 아닙니다.*

상세 페이지는 선택한 차량의 이미지와 모델명을 히어로 영역에 배치하고, 디자인 소개 → 퍼포먼스 소개 → 가격·제원 순서로 정보를 제공합니다. 스크롤에 따른 이미지 이동과 텍스트 등장 효과로 화면의 흐름을 구성했습니다.

## 06. 기술 및 구현 포인트

### HTML · 콘텐츠 구조

`header`, `main`, `section`, `footer`로 화면을 구성했습니다. 차량 이미지에는 대체 텍스트를, 캐러셀 이동 버튼에는 `aria-label`을 적용했습니다.

### CSS · 화면 표현

Flexbox로 가로 슬라이드를, Grid로 상세 콘텐츠와 제원 카드를 배치했습니다. `clamp()`와 미디어 쿼리로 화면 크기에 맞춰 글자 크기와 여백을 조정하고, `transform`·`transition`·`@keyframes`로 움직임을 표현했습니다.

### JavaScript · 데이터와 인터랙션

- **데이터 분리:** `js/data.js`에서 8개 모델의 이미지, 소개 문구, 제원 정보를 관리하고 메인과 상세 페이지에서 공유합니다.
- **동적 화면 생성:** 차량 데이터를 순회하며 슬라이드와 인디케이터를 생성합니다.
- **상세 페이지 재사용:** `URLSearchParams`로 차량 번호를 읽어 하나의 상세 페이지에 모델별 정보를 표시합니다.
- **스크롤 처리:** `requestAnimationFrame`과 상태 플래그로 패럴랙스 갱신을 예약합니다.

```text
.
├── index.html                 # 메인 캐러셀
├── detail.html                # 모델별 상세 페이지
├── css/
│   └── style.css              # 공통 스타일·반응형·애니메이션
├── js/
│   ├── data.js                # 차량 데이터
│   ├── main.js                # 캐러셀 및 사용자 입력 처리
│   └── detail.js              # 상세 화면 및 스크롤 효과
├── assets/
│   └── *.avif                 # 차량 이미지 8개
├── docs/
│   └── images/                # README용 메인·서브 이미지
└── README.md
```

## 08. 실행 방법

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 엽니다.
3. 로컬 파일 환경에서 이미지나 스크립트 로딩이 제한된다면 VS Code의 Live Server 등 로컬 서버로 실행합니다.

> 별도의 빌드 과정은 없습니다. 아이콘은 Bootstrap Icons CDN을 사용하므로 인터넷 연결이 필요합니다.

## 09. 발표 시연 순서

1. **기획 의도 소개** — 차량 이미지에 집중하는 화면과 메인에서 상세로 연결되는 탐색 흐름을 설명합니다.
2. **메인 화면 시연** — 자동재생, 좌우 버튼, 인디케이터, 드래그를 보여줍니다.
3. **상세 화면 시연** — 차량 이미지를 클릭하고 모델별 콘텐츠가 표시되는 과정을 보여줍니다.
4. **스크롤 인터랙션 시연** — 텍스트 등장 효과, 패럴랙스, 제원 영역을 확인합니다.
5. **반응형 화면 시연** — 화면 폭을 줄여 콘텐츠 배치와 제원 카드의 변화를 보여줍니다.
6. **구현 방식 설명** — 데이터 분리와 공통 상세 페이지 구조를 중심으로 설명합니다.
